# Alexander Johansson Portfolio

A personal frontend portfolio built to present selected projects, technical skills and background ahead of LIA applications.

The site is built with semantic HTML, SCSS and vanilla TypeScript, with a focus on accessibility, performance, responsive design and maintainable frontend structure.

## Live

[View the portfolio](https://alexjcodes.github.io/alexander-johansson-portfolio-2026/)

## Tech

- HTML5
- SCSS
- TypeScript
- Vite
- Biome
- Formspree
- GitHub Pages

## Features

- Responsive design for mobile, tablet and desktop
- Dark and light theme with saved user preference
- Accessible desktop and mobile navigation
- Horizontal project carousel
- Personal project and experience sections
- Interactive Padel Challenge
- Formspree integration for challenge submissions
- Open Graph metadata and social preview
- SEO metadata and sitemap
- Downloadable CV
- GitHub Pages deployment

## Accessibility & quality

The portfolio has been built with a focus on semantic and accessible frontend development.

- Semantic HTML structure
- Keyboard navigation
- Visible focus states
- Reduced motion support
- Responsive layouts
- W3C HTML validation
- Lighthouse testing
- Accessible native `<dialog>` for the Padel Challenge

## Run locally

**Install dependencies:**

``` bash
npm install
```

**Start the dev-server:**

``` bash
npm run dev
```

**Create a prod-build:**

``` bash
npm run build
```

## Code quality

**Run Biome checks:**

``` bash
npm run check
```

**Auto fix supported issues:**

``` bash
npm run check:fix
```
